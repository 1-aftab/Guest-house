# Pinecrest Stay

A polished boutique guest house website template designed for static GitHub Pages hosting.

## Stack
- Static HTML
- CSS
- Vanilla JavaScript
- No backend, database, booking engine or payment system

## Structure
```text
/
├── index.html
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── images/
        ├── hero.jpg
        ├── room-1.jpg
        ├── room-2.jpg
        ├── room-3.jpg
        ├── interior-1.jpg
        ├── interior-2.jpg
        ├── amenity-1.jpg
        ├── amenity-2.jpg
        ├── location-1.jpg
        └── location-2.jpg
```

## Before delivering to a client
1. Replace the 10 JPG placeholders in `assets/images/` with the client's photography, keeping the exact filenames.
2. Update property copy, room names/prices and nearby attractions in `index.html`.
3. Replace `WHATSAPP_NUMBER` in `assets/js/main.js` with the client's WhatsApp number (international format, digits only).
4. Replace the fictional address and Google Maps query in `index.html`.
5. Update title/description metadata if needed.

The WhatsApp button is enquiry-only. There is no availability, booking or payment logic.
